## GitHub Release

这一版主攻敌人美术，没动系统数值。

- 五种敌人（杂兵 / 奔行者 / 重甲 / 精英 / Boss）全部换成 2D 精灵，
  暗色腐化风，替换掉之前的占位模型
- 重做了命中判定：头部/弱点核改球形，躯干按轮廓分多段贴合，
  精英改成"圆环 + 中心独占发光眼"——打中眼睛才算爆头
- 副作用是瞄准变难了一点，难度顺带上去了，实测体感更紧

下一版 v0.6 做怪物逐帧动画（行走/奔跑/攻击/死亡）+ 武器 2D 持枪视图 + 地图贴图差异化。

## itch.io devlog

v0.5.0 出了。这次只做美术，玩法数值没动。

之前敌人是占位的低多边形模型，一直想换。这版五种敌人全部换成
手绘风 2D 精灵（暗色腐化调），命中判定也跟着重做了一遍——头部和
弱点改球形，躯干按剪影分段贴合，精英的发光眼做成独立爆头点。

顺带一个没预料到的效果：判定收紧后瞄准更吃准头，难度自然上去了，
自己测下来体感比之前紧，是好事。

下一版做怪物动画（现在还是静态 + 程序动效）和武器手持视图。

反馈走 itch 评论区或 GitHub Issue。
