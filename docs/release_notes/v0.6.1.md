## GitHub Release

v0.6 的反馈修补，主攻平衡、彩蛋、新手引导和羁绊信息。

- 手枪火力之前压过步枪，削了单发伤害、保留高射速；步枪重回持续主力，手枪靠手感和打腿立身
- G18 打腿彩蛋（致敬三角洲行动的夺舍流）：手枪打腿额外伤害（不超过爆头），命中有独立标记，留给你自己发现
- 新手教程：主菜单和暂停菜单加「操作说明」页；战斗中第一次会提示近战处决怎么用（不少人不知道近战能干嘛）
- 羁绊信息：激活时直接显示效果说明；商店里鼠标悬停羁绊标签看详情，差一张卡的会写出还差哪张
- 修复开放区域二段跳能跳出地图（现在会自动拉回）

下一版处理升级经济（后期卡池见底）。

## itch.io devlog

v0.6.1 出了，是 v0.6 的反馈修补。

手枪之前火力盖过步枪，这版削了单发伤害、保留高射速，步枪重新当持续主力。手枪靠手感和一个彩蛋立身——它原型是三角洲行动里的 G18，那边有个"夺舍流"打腿的玩法，所以这版手枪打腿有额外伤害（不超爆头），命中会有独立标记，留给你自己发现。

另外不少人不知道近战处决能干嘛，加了新手引导：主菜单和暂停里有「操作说明」页，战斗里第一次也会弹一下提示。羁绊也补了信息——激活时显示效果，商店里悬停标签能看详情和还差哪张卡。

还修了开放区域二段跳跳出地图的问题。

下一版收拾升级经济（后期没卡可买）。

反馈走 itch 评论或 GitHub Issue。
