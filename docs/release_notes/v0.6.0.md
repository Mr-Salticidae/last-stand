# v0.6.0 发布文案存档

发布日期：2026.05 · tag `v0.6.0`
主题：近战处决系统 + 敌人程序动效 + 三地图视觉差异化大改。

## GitHub Release

这一版加了近战，重做了地图观感。

- 近战处决（F 键）：近距撕裂刃应急近战，秒杀目标 + 当前武器满弹补给，解后期弹尽待毙；充能资源，每波清空补 1
- 敌人行走/攻击有了程序动效：走路步频颠簸、攻击朝你前刺，不再像滑行的纸片
- 三张地图视觉差异化：前哨站暖沙漠 / 训练场冷中性 / 仓库暗工业，统一的脏旧 grunge 质感 + 缝隙腐蚀渗红，各自身份地标（通讯塔 / 人形钢靶 / 货架）
- 移速封顶，叠速度卡不再无限滑铲
- 敌人设定改为"腐蚀"，开场白与文案同步

下一版做武器 2D 持枪视图 + 怪物逐帧动画 + HUD 重绘。

完整记录见提交历史。
