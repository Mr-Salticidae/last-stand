主题：局内经济改造（后期不再空转）+ 敌人步态动效 + 一批实测手感/卡顿修复。

## GitHub Release

这一版收拾了后期经济，重做了敌人的走路观感，修了一批实测出来的手感问题。

- **经济改造**：后期常被吐槽"钱花不掉、不用 build 随便买"。这版加了永续强化卡（军备扩充 / 永备装甲，无上限叠加、价格随层递增），常规卡池抽空后兜底出现、可反复买，把后期收入吃掉；受伤时还能买「应急补给」回满血。同时货币改为按比例获取（与结算分数解耦），制造稀缺，让 build 取舍真正有意义。
- **敌人步态动效重写**：走路从"左右摇晃的纸片"改成蹦跳步态——腾空上跳、落脚下砸挤压、向你前冲一下，有重量地逼近。
- **首次命中 / 首次处决卡顿修复**：命中发光、处决迸发粒子的 shader 原本在第一次出现时才即时编译，表现为卡一帧。现在开局预热掉。
- **霰弹音 / 爆头音修复**：霰弹多颗弹丸原本各播一次命中音，叠得很重还把爆头音挤掉；现在整发只播一次，爆头音也能听清了。
- **寻路抖动修复**：敌人近身/拥挤时不再原地抽搐。
- 仓库瘦身：清掉约 57MB 已弃用的资产源料。

下一版按玩家反馈继续调经济 / 难度曲线。

## itch.io devlog

v0.7.0 出了，主要收拾后期经济，顺手修了一堆实测手感问题。

后期老是钱花不掉、升级卡也抽空了，等于白攒钱。这版加了能无限叠的强化卡，卡池见底后兜底出现、可以反复买，价格越买越贵，把后期收入吃掉；受伤还能花钱回满血。货币也改成按比例拿，不再和分数一样多——钱变紧了，build 才需要取舍。（一开始调太狠有点"刮痧"，回调到了一个还能打的点。）

敌人走路也重做了观感，从左右晃的纸片变成有重量地蹦跳逼近。另外修了第一次命中/处决卡一帧、霰弹声音过重、爆头音听不到、敌人近身原地抽搐这几个实测问题。

反馈走 itch 评论或 GitHub Issue，下一版按反馈继续调。
