# v0.8.1 发布文案存档

发布日期：2026.07 · tag `v0.8.1`
主题：纯修复版。修 v0.8.0 菜单里印错的版本号，并把版本号收敛到单一真源。
玩法与 v0.8.0 完全一致，无尽模式没有任何改动。

---

## GitHub Release

v0.8.0 的菜单页右下角印着 **v0.7.0 DEMO BUILD**，设置页的资料卡也写着 **v0.7.0 / 2026.06**。

原因是版本号写死在三个互不相干的地方，v0.8.0 bump 版本时全漏改了：

- `scripts/ui/atmosphere_background.gd` 的 `hud_bot_right` @export 默认值
- `scenes/ui_common/atmosphere_background.tscn` 里 `HudBot/Right` 这个 Label 的序列化 text
- `scenes/settings_menu.tscn` 的 `ProfileCard/ProfileGrid/V2`

第一处是所有菜单页共用的背景组件，所以影响的是关卡选择 / 设置 / 高分 / 玩法说明 / 制作名单**每一页**。

这版把版本号收敛到 `scripts/game_version.gd` 一个 const，tscn 里不再留任何版本字面量，UI 一律在运行时取。以后改版本只改一个地方。

> 这个类是 `@tool` + `class_name` 而不是 autoload —— `atmosphere_background.gd` 本身是 `@tool` 脚本，在编辑器里运行时 autoload 单例并不存在，只有 `class_name` 注册的全局类拿得到。

没有其他改动。如果你已经下载了 v0.8.0，除了角标上的版本号，玩法和内容完全一样，不下这版也不影响。

## itch.io devlog

v0.8.1 是纯修复版，只有一件事：v0.8.0 的菜单角上印着「v0.7.0 DEMO BUILD」。

版本号写死在三个地方——共用背景组件的默认值、那个组件 tscn 里 Label 的序列化文本、还有设置页的资料卡——我 bump 版本时三处全漏了，而且是发布之后拍宣传截图才发现的。

这版把它收敛成一个 const，tscn 里不再留版本字面量，运行时统一取。以后不会再犯。

玩法零改动，无尽模式和 v0.8.0 完全一样。已经下载 v0.8.0 的可以不用管这版。
