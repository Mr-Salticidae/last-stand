# 敌人精灵逐帧动画 — 出图规范与系统说明

> 系统已落地（`scripts/enemy.gd`），**丢图即生效，无需改代码**。
> 没有帧文件夹时自动退回单张静态图，零破坏。

## 一、目录约定

每只怪的精灵图旁，放一个**同名文件夹**，按 clip 命名帧：

```
assets/sprites/enemies/
  grunt.png              ← 原单图（= 静止/默认帧）
  grunt/                 ← 同名文件夹（注意：不带 .png）
    walk_0.png  walk_1.png   [walk_2.png …]   ← 走路循环，≥2 帧
    attack_0.png            [attack_1.png …]   ← 前摇/出手，≥1 帧
    death_0.png             [death_1.png …]    ← 倒地，≥1 帧（系统显示最后一帧叠溶解）
```

加载逻辑：启动时按 `walk_0, walk_1, …` 顺序探测直到缺失。任一 clip 缺失则该 clip 不启用。

## 二、硬性要求（否则会抖位 / 穿帮）

1. **同尺寸同画幅**：与原图一致（如 grunt 为 1024×1536），透明背景（RGBA）。
2. **脚底对齐同一行**：精灵按中心锚定，各帧角色"脚线"必须在画布同一高度，否则帧间上下漂浮。
3. **躯干/头部位置稳定**：跨帧只让**腿/手臂动**，身体框不要整体位移或缩放（缩放/弹跳由程序步态负责，见下）。
4. **边缘干净**：无半透明光晕（精灵用 alpha_cut 硬切边）。

## 三、关键：怎么画才"真迈步"（而非漂浮）

漂浮感的根源是腿不动。双帧 DOOM 跑动的诀窍是**两帧腿位相反**：

- `walk_0`：**左腿前伸 / 右腿后蹬**
- `walk_1`：**右腿前伸 / 左腿后蹬**

身体、头、武器保持一致，只换腿（和配套的手臂摆动）。系统会按落脚相位在两帧间切换，叠上程序步态的腾空/落脚，就读作真实迈步。想更顺可加到 4 帧（接触→过渡→腾空→过渡）。

> 出图提示词思路：同一角色，固定正面视角、固定画幅、纯透明背景，
> 分别要 "left leg striding forward" / "right leg striding forward"；
> attack 要 "lunging strike pose, arms raised"；death 要 "collapsing to ground"。

## 四、与程序步态的分工

- **程序步态**（`enemy.gd::_update_sprite_juice`）负责：腾空上跳、落脚下沉挤压、向玩家前冲、受击挤压、呼吸浮动。
- **逐帧图**负责：腿/手臂的实际位姿变化。
- 二者叠加 = 有重量地真迈步。若真图本身已含明显上下起伏，可调小 `_GAIT_HOP` 避免双重弹跳。

## 五、已知后续项

- **死亡**目前是"切到 death 末帧 + 缩小溶解"，非逐帧播放倒地。要逐帧播放需扩 `_play_death_sequence`。
- **Elite（飞行眼 `elite_eye.png`）** 走另一套（飞行不触发走路帧），其待机脉动 / 攻击动画建议单独做。
