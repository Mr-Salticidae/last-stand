# 国内分发方案（v1.0.0 起）

制定日期：2026-08-16 · 背景：itch.io 国内访问有门槛，GitHub Releases 国内直连不稳，
宣发视频带来的路人玩家需要"浏览器点开就能下"的公开链接。

**弃用/不做**：蓝奏云（免费版单文件限 100MB，v1.0.0 包 103.5MB 超限）；
百度网盘（限速 + exe 分享有被封先例）；夸克/阿里云盘（下载需装 App 登录，路人转化损耗大）；
网页版（Godot Web 导出只支持 Compatibility 渲染器，本项目是 Forward+，3D FPS 移植成本高不值得）。

## COS 配置决策

- **地域**：国内任一（默认上海 ap-shanghai），用 COS 默认域名 → **无需 ICP 备案**
- **桶权限**：公有读私有写（直链下载的前提）
- **不挂 CDN**：CDN 国内加速必须自定义域名 = 必须备案，COS 默认域名直连已够用
- **链接形态**：用「对象地址」（永久），不要用「临时链接」（带签名会过期）
- **文件命名**：带版本号（LastStand-vX.Y.Z-windows.zip），每版上传新文件、更新对外链接
- **三道保险（必须配，防盗刷天价账单）**：
  1. 用量封顶：超阈值自动切断公有读（硬闸）
  2. 云监控告警：外网下行流量异常时短信通知
  3. 费用中心消耗预警：月消耗超阈值通知
- **费用预期**：外网下行 0.5 元/GB → 一次下载 ≈ 0.05 元，1000 次 ≈ 50 元；存储费忽略不计（0.1GB）

## 每版发布 checklist 增补

1. 无头导出 zip + 验证 exe 版本资源
2. GitHub Release（tag + zip + 中文 body + compare 链接）
3. **COS 上传新版 zip，核对直链可下**
4. **QQ 粉丝群文件更新 + 群公告**
5. B站动态：双下载入口（进群下载 + COS 直链）
6. itch.io 上传 + devlog
7. docs/release_notes/vX.Y.Z.md 回填各渠道定稿
